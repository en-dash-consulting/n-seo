# Agent instructions

The operating rules for any AI agent working in this repository are in
[CLAUDE.md](CLAUDE.md). They apply to every agent, not just Claude. The
non-negotiables: the queue is the single source of "what's next" and is only
edited through the documented flow; never generate community comment text;
respect the 28-day title freeze and the ~8-changes-per-week batching; decide
on the 90-day window; ship site changes as branches and PRs; read `data/` and
the daily log instead of re-running pulls.
